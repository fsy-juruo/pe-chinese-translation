### [974. Very Odd Numbers](https://projecteuler.net/problem=974)

A *very odd number* is a number which contains only odd digits and is divisible by $105$.
Further each odd digit occurs an odd number of times.

Define $\Theta (n)$ be the $n$th very odd number, then $\Theta (1) = 1117935$ and $\Theta(10^3) = 11137955115$.

Find $\Theta(10^{16})$.

### 974. 极奇数

若某数可被 $105$ 整除，其所有数位都是奇数且每一个奇数位都出现了奇数次，则称这个数是一个 *极奇数*。

记 $\Theta (n)$ 为第 $n$ 个极奇数，则 $\Theta (1) = 1117935$、$\Theta(10^3) = 11137955115$。

求 $\Theta(10^{16})$。
